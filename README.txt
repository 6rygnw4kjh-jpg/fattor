CANTARE — publicação no Netlify

1. Suba esta pasta para um repositório no GitHub (ou use o Netlify CLI: npm i -g netlify-cli; netlify deploy --prod).
2. No Netlify: Add new site > Import from Git > escolha o repositório. Não precisa de comando de build.
3. Em Site configuration > Environment variables, crie ADMIN_PASSWORD com a senha da área administrativa. Faça um novo deploy.
4. Abra o site, toque em "Área administrativa", entre com a senha. No primeiro acesso, o catálogo atual é publicado para todos.
